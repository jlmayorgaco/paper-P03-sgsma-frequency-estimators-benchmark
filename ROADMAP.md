# Roadmap

## 2.0.0 alpha

- Public CLI.
- YAML-runner for quick tests, estimator comparisons, and Monte Carlo slices.
- Canonical single-phase metric profile.
- Custom estimator loading.
- Hypothesis bank generation and execution.

## 2.1 single-phase public release

- Cleaner estimator plugin API.
- Report dashboards from OpenFreqBench run artifacts.
- More examples and tutorials.
- CI for Windows, Linux, and macOS.

## V3 three-phase benchmark

- Three-phase scenario container.
- Per-phase and symmetrical-component metric adapters.
- Three-phase estimator plugin examples.

## V4 WAMS benchmark

- OpenDSS and ANDES event manifests.
- Multi-bus and multi-device simulations.
- Network-aware estimator stress tests.
