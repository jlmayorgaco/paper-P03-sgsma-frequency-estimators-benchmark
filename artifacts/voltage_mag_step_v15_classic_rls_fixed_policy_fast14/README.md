# Magnitude Step Fixed-Policy Atlas

This directory contains the final report-level artifacts for the fast-estimator
magnitude-step experiment.

Primary PDF:

```text
metrics_dashboard_multipage.pdf
```

Key companion files:

```text
global_metrics_report.csv
rmse_by_estimator.csv
rmse_by_family.csv
deterioration_hypothesis_tests.csv
tuning_parameter_continuity.csv
amplitude_step_phase_dispersion.pdf
```

The committed artifact set is intentionally report-level. Per-run simulation
folders such as `Sweep_AmplitudeStep_*` and `_fixed_policy_tuning` are local
generated outputs and are ignored by Git.
