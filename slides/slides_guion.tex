{\large\bfseries\color{ofbTeal} Field events define the stress model}\\[5pt]
{\small\itshape\color{ofbMuted}Say:}\\[1pt]
\begin{itemize}[leftmargin=1.05em,itemsep=2.5pt,topsep=1.5pt]
\item Real inverter disturbances look nothing like a clean sine wave.
\item In events like Blue Cut, Odessa, and the Kauai oscillation, phase jumps, fast RoCoF, harmonics and noise all arrive at once.
\item So instead of inventing test signals, we let these real events define the stress cases the benchmark must cover.
\end{itemize}
\vspace{2pt}{\small\color{ofbBlue}$\rightarrow$ \itshape And here is the catch: the very tool we use to watch these events also shapes what we conclude.}\\[1pt]
\vspace{3pt}

{\small\itshape\color{ofbMuted}Say:}\\[1pt]
\begin{itemize}[leftmargin=1.05em,itemsep=2.5pt,topsep=1.5pt]
