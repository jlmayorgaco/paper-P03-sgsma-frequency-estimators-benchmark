{\large\bfseries\color{ofbTeal} Field events define the stress model}\\[6pt]
{\small\itshape\color{ofbMuted}Say:}\\[2pt]
\begin{itemize}[leftmargin=1.1em,itemsep=3pt,topsep=2pt]
\item Real IBR disturbances are not clean sine waves.
\item Blue Cut, Odessa, the Kauai oscillation: phase jumps, fast RoCoF, harmonics and noise stacked together.
\item We use these real events to define the stress cases the benchmark must cover.
\end{itemize}
